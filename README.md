# math-dic — 数学辞典 MATH ATLAS

黒板とチョークをモチーフにした、日本語の数学辞典です。PC・スマートフォン・タブレットの画面幅に対応します。

## 主な機能

- **80用語・7分野**：数と計算、式と方程式、関数・数列、図形、確率・統計、微分・積分、ベクトル・行列。
- 用語名・読み仮名・別名・キーワードで検索。分野・学習段階の絞り込み、しおり、閲覧履歴。
- 各用語に定義、詳しい解説、やさしい要約、数式、解説付き例題、間違えやすい点、参考資料。
- 解説・要約・自作公式の解説の日本語読み上げ。音声と速度の変更、一時停止・再開・停止。
- **マイ黒板／用語ごとの黒板**：指・タッチペン・マウス、筆圧、5色のチョーク、消しゴム、直線・四角形・円、文字入力、Undo/Redo、画像保存。
- **公式ラボ**：自分の式の作成・グラフ・日本語解説・代入手順・定義域の注意点・導関数・数値的な根探索。
- 観測データと式の誤差比較。一次〜三次の回帰候補を交差検証で比較し、候補を採用して式を改良。
- 自作公式の保存、変更履歴、過去版の復元、JSONバックアップの書き出しと読み込み。
- **手書きの数式化**：対応する文字の筆跡を端末内で照合し、候補を確認・修正して公式ラボへ。自分の字形の追加登録。

## 公開と起動

通常の利用にサーバー処理・APIキー・npmインストールは不要です。外部CDNやモデルのダウンロードにも依存しません。

### GitHub Pages

このリポジトリの `main` が配信元です。GitHub Pagesを使う場合は、リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** を選択してください。ルートの `index.html` が `dist/` のアセットを読み込みます。

Pages側でこの設定が済んでいれば、その後の `main` 更新がサイトへ反映されます。リポジトリへのコミットだけでは、GitHub Pagesの有効化やデプロイ成功を意味しません。

### ローカル

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。ES Modulesを使うため、HTMLをファイルとして直接ダブルクリックせずHTTPで配信してください。`dist/` 単体を任意の静的ホスティングへ置くこともできます。

## 公式ラボの使い方

`x^2-4x+7`、`2x+1`、`sin(x)`、`sqrt(x)`、`a*x^2+b*x+c` のように入力し、「分析・解説をつくる」を押します。二次式なら開き方・頂点・対称軸・定数項の意味を、計算の流れとともに説明します。

対応構文：`x`、係数 `a b c d`、定数 `pi e`、`+ - * / ^`、括弧、`sqrt abs sin cos tan exp log ln`。`log` は底10、`ln` は自然対数、三角関数はラジアンです。`y=` / `f(x)=` と暗黙の掛け算にも対応します。

数式は独自の安全な構文解析器で評価します。`eval` や `Function` は使用しません。数値の誤差・サンプリングの限界は結果の付近に表示します。解説は対応する式の構造から生成し、外部の生成AIは呼び出しません。式だけから物理的・経済的な用途を推定することはしません。

「進化」は、観測データから候補式を計算し、検証誤差や複雑さを比べ、利用者が選んで新しい版に保存する仕組みです。サイトが閉じている間に自動学習したり、一般的な数学的証明を生成したりする機能ではありません。

## 手書き認識の範囲

数字 `0–9`、`x y a b c`、基本演算記号 `+ − × ÷ / =`、括弧、小数点、簡単な上付き指数・上下に分けた分数に対応します。文字を少し離して、一つの短い式を大きめに書いてください。

これは独自の筆跡テンプレート照合です。すべての人の筆跡・続け書き・日本語の文章・積分記号・根号・任意の複雑な数式を認識する汎用OCRではありません。未知の字形は無理に確定せず、候補や注意を表示します。`x` と `×` などの曖昧な形は候補を選び、**必ず式を確認してから**分析へ進みます。

「自分の字を登録」は、黒板に一文字だけ書いて文字を指定する機能です。1文字につき8例まで保存し、その人の字形を候補の照合に使用します。照合スコアは認識精度の確率ではありません。

## 保存と音声

- 黒板は IndexedDB、自作公式・字形・しおり・設定はブラウザのローカル保存を使います。
- 端末間の同期やアカウント共有はありません。ブラウザの保存データを消すと内容が失われます。
- 大切な黒板は画像で、自作公式はJSONでバックアップできます。
- 日本語音声の種類・発音・利用可否は端末とブラウザに依存します。Web Speech APIの音声は、端末の設定によってネットワークを使う場合があります。

## ソース構成

| ファイル | 役割 |
|---|---|
| `dist/index.html`, `dist/styles.css`, `dist/app.js` | レスポンシブUI、辞典・検索・黒板・音声の連携 |
| `dist/data-foundations.js`, `dist/data-advanced.js` | 80用語の原稿・公式・例題・参考資料 |
| `dist/formulas.js` | 事前生成したネイティブMathMLと黒板用テキスト |
| `dist/blackboard.js` | 筆圧付き描画、操作履歴、端末保存 |
| `dist/speech.js` | 日本語読み上げと発話のライフサイクル |
| `dist/handwriting.js` | 筆跡認識・個人字形の登録 |
| `dist/formula-engine.js` | 安全な数式解析、解説、微分、回帰・交差検証 |
| `dist/formula-lab.js`, `dist/formula-lab.css` | 自作公式の編集・履歴・改善候補のUI |
| `scripts/check-content.mjs` | 用語・関連リンク・MathMLの検証 |
| `scripts/compile-formulas.mjs` | 用語のTeXからMathMLを生成 |
| `scripts/prepare-pages.mjs` | GitHub Pagesルート用HTMLを更新 |

内容を変更したときだけ、次のコマンドを使います。

```bash
npm install
npm run formulas
npm run check
node scripts/prepare-pages.mjs
```

通常の起動では、すでに生成済みのファイルをそのまま使えます。参考文献は各用語の末尾に掲載しており、OpenStaxや大学の公開教材を確認しながら独自の日本語解説を作成しています。
