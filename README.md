# math-dic — 数学辞典 MATH ATLAS

黒板とチョークをモチーフにした、日本語の数学辞典です。PC・スマートフォン・タブレットの画面幅に対応します。

## 主な機能

- **80用語・7分野**：数と計算、式と方程式、関数・数列、図形、確率・統計、微分・積分、ベクトル・行列。
- 用語名・読み仮名・別名・キーワードで検索。分野・学習段階の絞り込み、しおり、閲覧履歴。
- 各用語に定義、詳しい解説、やさしい要約、数式、解説付き例題、間違えやすい点、参考資料。
- 解説・要約・自作公式の解説の日本語読み上げ。音声と速度の変更、一時停止・再開・停止。
- **マイ黒板／用語ごとの黒板**：指・タッチペン・マウス、筆圧、極細を含む5段階の太さ、5色のチョーク、消しゴム、直線・四角形・円、文字入力、Undo/Redo、画像保存。
- **公式ラボ**：自分の式の作成・グラフ・日本語解説・代入手順・定義域の注意点・導関数・数値的な根探索。
- 観測データと式の誤差比較。一次〜三次の回帰候補を交差検証で比較し、候補を採用して式を改良。
- 自作公式の保存、変更履歴、過去版の復元、JSONバックアップの書き出しと読み込み。
- **手書きの数式化**：対応する文字の筆跡を端末内で照合し、候補を確認・修正して公式ラボへ。自分の字形の追加登録。

## 公開と起動

通常の利用にサーバー処理・APIキー・npmインストールは不要です。外部CDNやモデルのダウンロードにも依存しません。

### GitHub Pages

このリポジトリの `main` が配信元です。GitHub Pagesを使う場合は、リポジトリの **Settings → Pages → Deploy from a branch → main / (root)** を選択してください。ルートの `index.html` が `dist/` のアセットを読み込みます。

Pages側でこの設定が済んでいれば、その後の `main` 更新がサイトへ反映されます。リポジトリへのコミットだけでは、GitHub Pagesの有効化やデプロイ成功を意味しません。

### ローカル

```bash
python3 -m http.server 8000
```

`http://localhost:8000/` を開きます。ES Modulesを使うため、HTMLをファイルとして直接ダブルクリックせずHTTPで配信してください。`dist/` 単体を任意の静的ホスティングへ置くこともできます。

## 公式ラボの使い方

`x^2-4x+7`、`2x+1`、`sin(x)`、`sqrt(x)`、`a*x^2+b*x+c` のように入力し、「分析・解説をつくる」を押します。二次式なら開き方・頂点・対称軸・定数項の意味を、計算の流れとともに説明します。

対応構文：`x`、係数 `a b c d`、定数 `pi e`、`+ - * / ^`、括弧、`sqrt abs sin cos tan exp log ln`。`log` は底10、`ln` は自然対数、三角関数はラジアンです。`y=` / `f(x)=` と暗黙の掛け算にも対応します。

数式は独自の安全な構文解析器で評価します。`eval` や `Function` は使用しません。数値の誤差・サンプリングの限界は結果の付近に表示します。解説は対応する式の構造から生成し、外部の生成AIは呼び出しません。式だけから物理的・経済的な用途を推定することはしません。

「進化」は、観測データから候補式を計算し、検証誤差や複雑さを比べ、利用者が選んで新しい版に保存する仕組みです。サイトが閉じている間に自動学習したり、一般的な数学的証明を生成したりする機能ではありません。

## ペン入力と書きやすさ

「大きく書く」で黒板を画面いっぱいに広げられます。筆跡の縦横比は維持し、道具・読み取り・保存ボタンを同じ画面で使えます。細かな指数や小数点は「極細」「細い」で書けます。選んだ色と太さは次回も引き継ぎます。

- 確定した筆跡をキャッシュし、筆記中は増えた区間だけを描き足します。過去の線を毎フレームたどり直す処理を削減しました。
- ブラウザが提供する高頻度入力・まとめられた入力点を取得し、同じ点の二重取得を避けます。未対応環境では通常のPointer Eventsを使います。
- 移動の検出は表示上のピクセルを基準に行い、軽い筆圧や小さな動き、点、ペンを離した位置を保持します。表示する線は角を残して滑らかにし、認識には実際に取得した筆跡を使います。
- ペンを検出すると指より優先し、直前の手のひららしい入力や複数の指の接触を除外します。指だけでも書けます。ペン・接触範囲を端末が通知しない環境では、手のひらを完全には区別できません。
- 保存タイマーが次の筆記を途中で切らないようにしました。長い一筆は点を捨てずに分割保存し、Undoでは一筆として戻します。従来の黒板データも読み込めます。

入力の頻度・筆圧・ペン識別は端末とブラウザの対応に依存します。物理ペンの実機試験や、遅延・認識率の一律保証を行ったものではありません。

## 手書き認識の範囲

数字 `0–9`、`x y a b c d`、円周率 `π`、基本演算記号 `+ − × ÷ / =`、括弧、小数点、簡単な上付き指数・上下に分けた分数に対応します。文字を少し離して、一つの短い式を大きめに書いてください。

微小な揺れを整え、複数の文字分割候補、傾き・幅の補正、線の端や閉じた輪の特徴を比べて候補を作ります。近くの文字を一つにまとめる場合と分ける場合を比較し、式の構文と上下の配置を合わせて順位を付けます。高頻度の筆跡や分割保存された長い一筆も、再標本化して照合します。

通常はWeb Workerで読み取るため、認識の計算が描画スレッドを占有しません。読み取り後に書き直したり黒板を切り替えたりした場合は古い処理を中断し、古い候補を出しません。Workerが使えない環境では、量を制限した同じ認識処理で代替します。読み取りは端末内で完結します。

これは独自の筆跡テンプレート照合です。すべての人の筆跡・続け書き・日本語の文章・積分記号・根号・任意の複雑な数式を認識する汎用OCRではありません。未知の字形は無理に確定せず、候補や注意を表示します。`x` と `×` などの曖昧な形は候補を選び、**必ず式を確認してから**分析へ進みます。

「自分の字を登録」は、黒板に一文字だけ書いて文字を指定する機能です。1文字につき16例まで保存し、その人の字形を候補の照合に使用します。照合スコアは認識精度の確率ではありません。

## 誤操作による画面変更の抑制

本文の文字選択、ダブルクリック／ダブルタップによる選択や拡大、長押し・右クリックのコンテキストメニュー、リンクや画像のドラッグ、ページ内のピンチ操作、Ctrl/Cmdを押しながらのホイールや拡大縮小キーを抑えています。入力欄のリサイズハンドルも非表示です。

通常のスクロール、入力欄の文字編集・キーボード貼り付け、黒板の手書きは利用できます。入力欄の編集は維持するため、ブラウザ／OSが独自に表示する文字編集UIやアクセシビリティの拡大、ブラウザ本体のメニューまですべて禁止できるものではありません。

画面操作の保護は `dist/interaction-guard.css` と `dist/interaction-guard.js` で行い、どの画面にも共通で適用します。

## 読み上げの精度

- 辞典の用語名は登録済みの読み仮名を使い、本文・要約・例題には数学用語の読み辞書を適用します。一般語の一部分を誤って置換しないよう、文脈が必要な一文字の語は限定して扱います。
- 各用語の公式は専用の日本語原稿で読みます。括弧の範囲、分子・分母、累乗や根号の範囲を明示します。
- 自作公式と解説中の数式は構造を解析して読みます。分数、符号、暗黙の掛け算、括弧、累乗、平方根、対数などの意味を保ち、常用対数と自然対数も区別します。
- 日本語音声だけを選択肢に表示します。読み込み済みの音声一覧に日本語がない場合、別言語で強行再生せず、音声設定を案内します。
- 長い解説は文・句読点・単語の境界で分け、再開時も単語の途中から始まらないようにします。

表示内容と読み上げ用の文章を分けています。読み辞書と対応構文の変換によって誤読を減らしますが、音声合成エンジンのアクセントや未対応の記法まで完全に保証するものではありません。

## 保存と音声

- 黒板は IndexedDB、自作公式・字形・しおり・設定はブラウザのローカル保存を使います。
- 端末間の同期やアカウント共有はありません。ブラウザの保存データを消すと内容が失われます。
- 大切な黒板は画像で、自作公式はJSONでバックアップできます。
- 日本語音声の種類・発音・利用可否は端末とブラウザに依存します。Web Speech APIの音声は、端末の設定によってネットワークを使う場合があります。

|---|---|
| `dist/index.html`, `dist/styles.css`, `dist/app.js` | レスポンシブUI、辞典・検索・黒板・音声の連携 |
| `dist/data-foundations.js`, `dist/data-advanced.js` | 80用語の原稿・公式・例題・参考資料 |
| `dist/formulas.js` | 事前生成したネイティブMathMLと黒板用テキスト |
| `dist/blackboard.js` | 筆圧付き描画、操作履歴、端末保存 |
| `dist/speech.js` | 日本語音声の選択、発話の分割・停止・再開 |
| `dist/math-speech.js`, `dist/speech-lexicon.js` | 数式の読み変換・数学用語の読み辞書 |
| `dist/interaction-guard.css`, `dist/interaction-guard.js` | 誤選択・長押しメニュー・拡大操作の抑制 |
| `dist/handwriting.js` | 文字分割・筆跡認識・個人字形の登録 |
| `dist/handwriting-client.js`, `dist/handwriting-worker.js` | 別スレッドでの読み取り・中断・互換処理 |
| `dist/formula-engine.js` | 安全な数式解析、解説、微分、回帰・交差検証 |
| `dist/formula-lab.js`, `dist/formula-lab.css` | 自作公式の編集・履歴・改善候補のUI |
| `scripts/check-content.mjs` | 用語・関連リンク・MathMLの検証 |
| `scripts/check-speech.mjs`, `scripts/check-speech-lifecycle.mjs` | 数式の読み・辞書・音声制御の回帰検証 |
| `scripts/check-blackboard.mjs`, `scripts/check-handwriting.mjs`, `scripts/check-handwriting-client.mjs` | 高頻度入力・保存・認識・Worker制御の回帰検証 |
| `scripts/compile-formulas.mjs` | 用語のTeXからMathMLを生成 |
| `scripts/prepare-pages.mjs` | GitHub Pagesルート用HTMLを更新 |

内容を変更したときだけ、次のコマンドを使います。

```bash
npm install
npm run formulas
npm run check
node scripts/prepare-pages.mjs
```

通常の起動では、すでに生成済みのファイルをそのまま使えます。参考文献は各用語の末尾に掲載しており、OpenStaxや大学の公開教材を確認しながら独自の日本語解説を作成しています。
